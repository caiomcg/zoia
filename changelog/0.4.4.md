### Improved

- **Settings › Updates only asks for the Git repository.** Zoia now finds new versions from
  that repository's published releases, so the branch and manifest path settings are gone.
- **New versions are offered as soon as they are published.**

### Good to know

- The repository has to be on GitHub. A branch or manifest path set before is no longer used.
