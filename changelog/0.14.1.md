---
summary: Zoia tells you when it can't share a window and restarts so it can, and volume sliders stop jumping to 100%.
---

### Fixed

- **Sharing a window failed when Zoia ran as administrator.** Windows doesn't let Zoia capture a
  window then. Zoia now says so in a banner with **Restart normally**, which reopens it as you,
  so sharing works again. If a window can't be shared because its own program runs as
  administrator, Zoia says that instead.
- **A volume slider no longer jumps to 100% when clicked twice quickly.** To go back to 100%,
  use the small button that appears beside the number.

### Improved

- **Zoia installs just for you, with no choices to make.** The installer no longer offers to
  install for everyone in Program Files, where every update needed administrator rights.

### Good to know

- If Zoia is already installed for everyone on your computer, it keeps working as before.
- The administrator banner and the installer change are for Windows; the volume sliders are fixed everywhere.
