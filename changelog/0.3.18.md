### New

- **Zoia on the Mac.** Zoia now runs on macOS 13 or later, on Apple silicon and Intel. A Mac
  can join channels, watch, use the camera, and share a screen or a window, encoded in
  hardware by the Mac itself.
- **Mac shares carry the system's audio.** When you share from a Mac, everything the Mac plays
  is sent with it — other apps and notifications included — except Zoia's own sound, so
  nobody hears themselves echoed back. Zoia reminds you of this every time you start sharing.
  Sending a single application's audio is still Windows-only.

### Good to know on a Mac

- **First open:** Zoia is not signed with an Apple developer account, so the first time,
  right-click the app and choose **Open**, then confirm.
- **Screen recording permission:** macOS asks the first time you share. If you said no, turn
  it on in **System Settings › Privacy & Security › Screen & System Audio Recording**, then
  reopen Zoia.
- **Updates:** a Mac updates by downloading the new disk image. When an update is out,
  **Check now** takes you to its release page.
- **One quality per Mac share:** a Mac sends its screen at full quality only, so viewers on a
  weak connection cannot switch it to a lower one. A Mac camera is unaffected.
- **Invites:** if Zoia does not pick up an invite file placed next to it, drop the file onto
  the Zoia window instead.

### Windows

- Nothing changes in how Zoia works on Windows. This release does need the installer,
  because the way the app is packaged changed to make room for the Mac build.
