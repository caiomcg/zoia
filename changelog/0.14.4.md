summary: Bold, italics, spoilers and the rest of Discord's formatting in chat, with a formatting bar.
---

### New

- **A formatting bar.** The new button beside the emoji button opens a bar over the message
  box with bold, italics, underline, strikethrough, spoiler, code, code block, quote and list.
  Each button styles the selected words, or takes the style off; with nothing selected it
  starts the style where you're typing. Quote and list apply to every line you've selected.
  The bar stays open until you close it, and **Ctrl+Z** undoes a change made from it.
- **Shortcuts.** **Ctrl+B**, **Ctrl+I**, **Ctrl+U** and **Ctrl+Shift+X** (strikethrough) work
  in the message box and when editing a message. On a Mac, use **Cmd** instead of Ctrl.

### Fixed

- **Formatting in chat messages.** Messages used to show exactly what was typed, so
  `**bold**` came out with its stars. They now show Discord's formatting: bold, italics,
  underline, strikethrough, spoilers, inline code and code blocks, headings, small text,
  quotes, lists and links with their own text (`[text](https://…)`). Web addresses, mentions
  and code are left as they are, so an underscore in a link never turns into italics.

### Good to know

- A spoiler stays hidden until you click it. In the quote above a reply, spoilers always stay
  hidden.
- Messages sent before this version show their formatting too.
- Windows and Mac. People on older versions of Zoia see the formatting marks as typed.
