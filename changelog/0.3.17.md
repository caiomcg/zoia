### New

- **What's new, after every update.** The first time Zoia starts on a new version, it opens a
  short summary of what changed — this one included. It appears once per version, and only
  after Zoia has finished loading, never over the pairing screen.
- **Release notes on demand.** Click the version number in **Settings → About** to read the
  notes for the version you are running, with a link to the full release on GitHub.

### Improved

- **Clearer release pages.** Each release on GitHub now carries a written summary like this
  one, instead of a bare list of changes.

If Zoia is offline when it starts after an update, the notes simply wait until the next
start.
