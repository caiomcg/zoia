### Fixed

- **League of Legends window switching.** Sharing League of Legends on Windows now smoothly
  switches to the game window when a match starts and returns to the lobby after the match ends,
  restoring the client window if Windows minimized it.

### Improved

- **Refresh available windows on demand.** A new refresh button beside the search bar in the
  screen picker updates the list of open windows and screens immediately.
- **Tip for game capture.** The window picker now includes guidance on why games running in
  exclusive fullscreen minimize when switching apps, recommending borderless windowed mode
  or full screen sharing.
- **Cleaner window placeholders.** Windows loading their first thumbnail show a subtle display
  outline instead of a blank black tile.

### Good to know

- On Windows, games running in exclusive fullscreen minimize when you Alt+Tab to another app.
  To keep your game visible while sharing, set it to borderless windowed mode in the game's
  video settings, or select your screen instead of a single window.
