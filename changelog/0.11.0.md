summary: Addons, starting with a music bot for voice, plus finer voice volume.

### New

- **Addons.** The super admin can add to what the server does, from **Settings → Addons**:
  type an addon's GitHub repository, read what it asks to be allowed to do, and install it.
  From the same place, turn it on or off, update it, uninstall it, read its logs, choose the
  chats it listens to, rename its commands for everyone, and fill in its own settings.
- **Commands in the chat.** Typing `!` at the start of a message lists the commands the
  addons in that chat answer, with what each does. Arrow keys and Tab pick one.
- **Bots.** An addon can have bots of its own. A bot wears a **BOT** tag by its name, in the
  channel list and in the chat, and its messages are tinted so they stand apart. A bot in
  voice is heard like anyone in voice, with its own volume in its menu.
- Admins can take a bot out of a channel from its menu, as they can a person.

### Improved

- **A person's voice volume** moves by 1 % instead of 5 %, and the mouse wheel over the
  slider moves it too.

### Good to know

- **Addons are for the super admin alone** to install. An addon runs its author's code on the
  server, with what it was allowed; Zoia shows what it asks for before anything is installed.
- An addon asking for more in a new version needs the super admin to allow it before it
  updates.
- An addon may delete its own bots' messages, and, if allowed, the commands people typed to
  it, so it can tidy the chat up after itself.
- A deleted message's space on the server is now freed about an hour after it is deleted,
  not ten days.
