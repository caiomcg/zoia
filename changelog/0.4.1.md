### New

- **See your own broadcast while sharing with hardware acceleration.** The stage shows what
  viewers receive, where it used to say there was no local preview.
- **Settings › Broadcast › Outline the shared window in yellow.** Windows 11 draws a yellow
  border around a window being captured; it is now hidden unless you turn this on.

### Improved

- **Hardware acceleration is on by default** (Settings › Broadcast › Hardware acceleration).
  If you had turned it off, it stays off.
- **Sharing a whole screen with an NVIDIA graphics card** now works the same way as sharing a
  window: encoded on the graphics card and sent with the rest of the broadcast. It no longer
  sometimes fails to start and falls back to the slower way.

### Fixed

- **A shared window that changes size is followed properly** with an NVIDIA graphics card.
  Making a game fullscreen used to send only a corner of it, and going back to a window left a
  frozen picture around it. The picture now keeps its size for the whole broadcast, with black
  bars if the window's shape changes.
- **Windows that only redraw now and then no longer lag behind** with an NVIDIA graphics
  card. A click, a scroll or typing in a browser could take seconds to reach viewers.

### Good to know

- With hardware acceleration now on by default, AMD and Intel graphics also encode on the
  graphics card. If that cannot start, Zoia shares the usual way instead.
- Windows 10 cannot hide the yellow border, so it stays there.
- Sharing a whole screen still sends no sound.
